Переключиться на предыдущий коммит
Выполни:
git switch --detach 77a2136

 Вернуться к текущему состоянию
Если проблема осталась или нужно вернуть последние изменения:
git switch master

увидеть ветку с ID в виде графа
git log --all --graph --decorate --oneline 
git log --oneline --decorate -15 77a2136
